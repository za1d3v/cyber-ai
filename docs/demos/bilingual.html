What this shows a client: a guardrail written only in English is close to useless against Chinese-language or character-obfuscated injections — the real-world gap behind reports that some Chinese-developed models are far more susceptible to agent hijacking. Normalization is the cheapest high-value fix; a bilingual filter helps; but code-switching and instructions hidden inside documents still require prompt hardening and output filtering.
